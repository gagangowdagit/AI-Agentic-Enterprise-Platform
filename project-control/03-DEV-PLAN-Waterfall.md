# Delivery Milestones

This file is a milestone-oriented view of the canonical roadmap in `03-DEV-PLAN-Agile.md`. It is useful for recruiter and release conversations; task-level truth belongs in the Agile roadmap.

| Milestone | Outcome | Status |
|---|---|---|
| M0 Foundation | Repository, Java/Spring backend, React frontend, API conventions, tests | DONE |
| M1 Core data | PostgreSQL/JPA/Flyway entities, repositories, project/team/document workflows | PARTIAL |
| M2 Secure platform | JWT/session security, RBAC, protected APIs, authorization tests | NEXT |
| M3 Knowledge ingestion | Validated upload, extraction, chunking, embedding, processing status | PARTIAL |
| M4 Grounded RAG | Reliable retrieval, source-aware answers, model health, evaluation set | PARTIAL |
| M5 Nova AI | Durable chat, streaming/polling, citations, resilient UX | PARTIAL |
| M6 Controlled agents | Audited tools, authorization, confirmation, execution lifecycle | PARTIAL |
| M7 Operational intelligence | Analytics, reports, memory, notifications, scheduled insights | PLANNED |
| M8 Reliable scale | Async jobs, retries, real-time status, caching/vector infrastructure where justified | PLANNED |
| M9 Production readiness | CI, containers, observability, security review, deployment and recovery | PLANNED |

The product remains in progress. Dates are intentionally omitted until each milestone has a measurable acceptance test and a stable dependency path.
